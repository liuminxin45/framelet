## 接口收敛

- 删除阻塞式 MCP 录制、schema-1 时间线读取、缺失区间补齐、资产 ID 猜测及 SDK 多版目录容忍分支。
- 当前 MCP 协议 2025-11-25、目录 2.0、20 个工具；录像统一后台任务。时间线仅 schema 2；各持久化文件有独立版本命名空间，不按数字大小混为一种格式。
- 单 GIF 在 CLI/MCP/GUI 中统一最长 300 秒，长录制使用分组轮转。产品当前 fps/quality 默认值仍是现行配置；待实施的清晰度 API 不保留这些参数的翻译兼容层。

## 实际验证

20 个单元测试、11 组集成回归全部通过。格式检查、Clippy 零警告、actionlint、53 个依赖的 OSV 查询及便携包解压校验通过。OSV 未返回已知漏洞不等于不存在漏洞。

中断测试使用实际 GDI 录制、64×64 全遮挡区域，避免采集私人屏幕/键盘内容：停止后再取消、倒计时取消后再停止、暂停时停止、worker 挂起与停止期限、宿主在暂停中强杀、单 GIF/分组响应管道断开，以及已接受停止后的响应管道断开。断开后检查进程回收，失败后验证下一任务成功。宿主强杀后用新进程恢复检查点，验证二次恢复无重复分段。

单元测试逐一模拟 GIF、时间线、manifest、receipt 发布后索引尚未提交的中断；再次恢复必须复用已校验字节、补齐缺失步骤、拒绝冲突且保持已有文件。事件 ID 存在但关联到错误区间、画面或偏移时必须拒绝。

独立测试包括 GIF 解码/时序、遮罩、编辑、CLI/MCP、60 FPS、轮转与检查点、1000 次固定种子变异及官方 SDK；详细退出码/耗时见 [JSON 证据](interruption-safety-2026-11-02.json)。

## Actions 与范围

工作流配置 Windows 2022/2025 双环境、Python 3.12/Node 22、固定 SHA 的 Actions、逐测试超时与进程树清理、失败证据和真实便携包验收。每周或显式手动请求另跑 CLI/MCP 各 650 秒（300+300+50）。本报告是本地结果；远端结果必须按提交 SHA 在 Actions 检查。此次未在本地重新运行 650 秒，不引用其他 EXE 的长测冒充本次证据。

可恢复范围是已发布分段与已持久化、通过内容校验的检查点；未落盘观察、物理断盘/断电零丢失和所有文件系统语义均不在本次实测保证内。要求见 [工程强制规范](../engineering-standard.md)。
